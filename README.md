# AWS Three-Tier Web Application

## Overview

This project demonstrates the deployment of a secure three-tier web application on AWS using EC2 instances, VPC networking, Security Groups, Nginx Reverse Proxy, and Python Flask.

## Architecture

Internet
↓
Frontend EC2 (Nginx Reverse Proxy)
↓
Backend EC2 (Python Flask Application)

## AWS Services Used

* Amazon EC2
* Amazon VPC
* Public Subnet
* Private Subnet
* Security Groups
* Nginx Reverse Proxy
* Python Flask

## Features

* Secure frontend and backend communication
* Backend server accessible only through private networking
* Reverse proxy implementation using Nginx
* Flask application deployment on Linux
* Security group configuration for controlled access
